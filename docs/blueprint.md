# **App Name**: ProStock

## Core Features:

- Item List Display: Display a paginated list of items with detailed information like name, category, stock, and price, including a calculated margin column.  Support the following sortable columns: name, sku, stock, price, cost, and margin
- Item Filtering: Enable filtering the displayed items by category, stock alert status (low stock), and search term.
- CSV Export: Allow exporting the currently displayed items as a CSV file with specified columns.
- CSV Import: Allow importing items from a CSV file, updating existing items based on SKU and creating new items if the SKU doesn't exist.
- Dynamic Item Form: Dynamic form that adapts based on whether the item is simple or composite, showing relevant fields and disabling others.
- Component Management: For composite items, allow searching for and adding ingredient items with specified quantities, and calculate the total cost based on component costs.
- AI-Powered Item Suggestion: Suggest a user-friendly name for a new inventory item, and populate its description, using a generative AI tool based on product images uploaded by the user.

## Style Guidelines:

- Primary color: Indigo (#4B0082) to evoke feelings of precision, authority, and reliability which are good qualities for inventory management software.
- Background color: Light gray (#F0F0F0), offering a clean, neutral backdrop that ensures legibility and reduces eye strain during extended use. 
- Accent color: Violet (#8A2BE2), adds a layer of sophistication and helps highlight key interactive elements.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text, for a balance of modernity and readability.
- Use a consistent set of minimalist icons to represent categories and actions, focusing on clarity and ease of understanding.
- Implement a clean, intuitive layout with clear visual hierarchy. Use whitespace effectively to prevent clutter and improve readability.
- Use subtle transitions and animations to provide feedback on user interactions and guide the user through the interface. Animations should be used sparingly to avoid distraction.
